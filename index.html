Optimization & Hardware Interoperability

Memory utilization and garbage collection are persistent bottlenecks in Python-based computer vision pipelines. To build cost-effective, hardware-agnostic solutions that don't rely strictly on Nvidia GPUs, I leverage C++ interfaces like the Vulkan API and OpenCL.

A practical example is CompareCompress—a single-day build of an image compression comparer that achieves high-speed performance on legacy hardware (a 2017 MacBook Air) with minimal overhead.
